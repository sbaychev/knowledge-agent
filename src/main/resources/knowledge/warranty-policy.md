# Warranty Policy

Document version: 1.0

This is demonstration policy content for the Knowledge Agent project.
Replace it with the actual product policy before using the agent for real customers.

## Coverage period

The demonstration warranty covers manufacturing defects for 24 months
from delivery.

## Exclusions

The demonstration policy does not cover accidental damage, misuse,
or normal wear and tear.

## Support request

A customer requesting warranty support should provide the order ID
and a description of the issue. Supporting photos may help the support
team investigate the request.

The agent must not claim that a warranty request has been approved
unless an authoritative system confirms that decision.
