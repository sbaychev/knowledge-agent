# Refund Policy

Document version: 1.0

This is demonstration policy content for the Knowledge Agent project.
Replace it with the actual product policy before using the agent for real customers.

## Return window

A return request may be submitted within 30 calendar days of delivery.
Items must be unused and returned in their original packaging.

## Refund processing

Returned items are inspected before the refund is approved.
After approval, refund processing normally takes five to ten business days.

## Shipping charges

Original shipping charges are not refundable unless the item was faulty
or damaged, subject to the applicable return process.

## Current refund status

Use the live payment and refund lookup tools to answer questions about
a specific order. This policy document does not contain an individual
customer's refund status or transaction history.
